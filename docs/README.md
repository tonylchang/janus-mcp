# Docs

These Markdown files are the **canonical documentation** for janus-mcp —
review changes here first. The public website
([janus-mcp.ns47.com](https://janus-mcp.ns47.com), source in `../website/`)
is a styled mirror; when the two disagree, this directory wins and the
website needs a sync.

- [quickstart.md](quickstart.md) — install, configure, register with MCP clients
- [runbook.md](runbook.md) — operations: RBAC, approvals, audit log, troubleshooting
- [threat-model.md](threat-model.md) — the five security invariants and how CI verifies them

`assets/` holds images referenced by the top-level README.
